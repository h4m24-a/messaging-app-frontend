# Messaging App Frontend

## View Project : 

- React
- Vite
- Tailwind
- CSS
- Tanstack query
- React Router



## Features
- Direct messaging between registered users
- Secure user authentication and authorization
- Customiable user profiles (bio, profile image)
- Responsive design for desktop and mobile devices
- User search to start new conversations
- Input validation and error handling
- RESTful API for authentication, user management, and messaging
- Client-server architecture with separate frontend and backend
