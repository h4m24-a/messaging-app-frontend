# Messaging App Frontend

## View Project : https://messaging-app-frontend-production.up.railway.app

- React
- Vite
- Tailwind
- CSS
- Tanstack query
- React Router



## Features
- Secure user authentication flow (login and registration)
- Responsive messaging interface for desktop and mobile
- Direct messaging between registered users
- User search to start new conversations
- Customisable user profile (bio, profile image)
- Client-side form validation and error handling
- Protected routes for authenticated users
